import hashlib, math

VECTOR_DIM = 32

def embed_text(text):
    vec = [0.0] * VECTOR_DIM
    for token in text.lower().split():
        digest = hashlib.sha1(token.encode("utf-8")).hexdigest()
        bucket = int(digest, 16) % VECTOR_DIM
        vec[bucket] += 1.0
    norm = math.sqrt(sum(v * v for v in vec))
    if norm > 0.0:
        vec = [v / norm for v in vec]
    return vec

# Test: empty string -> all-zero vector

### Exactly-once guarantee — how it works

The two-phase commit pattern used here is:

```
1. poll batch from Kafka
2. upsert batch to LanceDB  (write first)
3. commit Kafka offsets      (commit second)
```

**If the process crashes between 2 and 3**, Kafka redelivers the same records on restart. Because the write is an *upsert on `id`*, replaying those records is a no-op — no duplicate rows are created.

**If the process crashes between 1 and 2**, nothing was written and nothing was committed; Kafka redelivers and the consumer retries normally.

This is safe in both crash windows.

---

### Key implementation points

| Requirement | Implementation |
|---|---|
| Manual offset commits | `enable.auto.commit=false`; `consumer.commit(offsets=…, asynchronous=False)` called only after `upsert_batch()` returns |
| Idempotent writes | `table.merge_insert("id").when_matched_update_all().when_not_matched_insert_all().execute(batch)` — upsert on the document `id` |
| Multi-partition offset tracking | Per-batch, the code finds `max(offset)` per partition and commits `max+1` for each, so offsets from all assigned partitions advance correctly |
| Rebalance safety | `on_revoke` callback calls `consumer.commit(asynchronous=False)` so in-flight offsets (already written) are committed before partitions transfer |
| Drain & clean exit | `IDLE_POLLS_TO_EXIT=5` consecutive polls returning 0 messages (2 s each = 10 s idle) triggers a clean exit with `sys.exit(0)` |
| Re-run idempotency | `open_or_create_table` opens the existing table if present; the upsert handles any already-persisted ids |
| Deterministic embedding | SHA-1 bucket accumulation + L2-normalisation, float32, dim=32 — no network calls |
| Schema | `id string, text string, source string, ts int64, partition int64, offset int64, vector fixed_size_list<float32>[32]` |
| Resource naming | Reads `/logs/artifacts/run-id` → `zr4lgs5okw`; topic `ingest-docs-zr4lgs5okw`, group `ingest-group-zr4lgs5okw`, table `documents_zr4lgs5okw` |

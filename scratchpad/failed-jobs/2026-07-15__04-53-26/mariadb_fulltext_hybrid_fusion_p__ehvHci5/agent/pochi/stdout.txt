- `_keyword_search` opens a PyMySQL connection to MariaDB and runs a parameterised `MATCH(body) AGAINST (%s IN NATURAL LANGUAGE MODE)` query ordered by relevance DESC with `id ASC` tie-break, returning the ids in strict keyword-rank order.

**RRF logic**
- For each list the doc appears in, add `1 / (60 + rank)` where rank is 1-based.
- Docs absent from a list contribute nothing for that list, so both-list hits naturally outrank single-list hits while still surfacing them.

**Determinism**
- MariaDB: explicit `ORDER BY rel DESC, id ASC`.
- LanceDB: explicit `sort_values(by=["_distance", "id"], kind="mergesort")`.
- Final list: `sorted(..., key=lambda item: (-item[1], item[0]))` then slice `[:k]`.
